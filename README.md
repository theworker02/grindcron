# grindcron

Grind numeric cron values, ranges, and human-readable units.

**Site:** https://theworker02.github.io/grindcron/

## Install / run

```bash
git clone https://github.com/theworker02/grindcron.git
cd grindcron
node src/cli.js
node --test
```
